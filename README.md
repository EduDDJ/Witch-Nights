# Witch-Nights 🎮

A game for the Game Design class (*Jogo para a aula de Design de Jogos*).

## 🚀 Play Online

The game is deployed on GitHub Pages: **[Play Witch-Nights](https://EduDDJ.github.io/Witch-Nights)**

## 💻 Development Setup

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/EduDDJ/Witch-Nights.git
   cd Witch-Nights
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run development server:**
   ```bash
   npm run dev
   ```
   The game will be available at `http://localhost:3000`

### Build for Production

To build the game for deployment:

```bash
npm run build
```

The built files will be in the `dist/` directory.

### Preview Production Build

To test the production build locally:

```bash
npm run preview
```

## 🚢 Deployment

### Deploy to GitHub Pages

The repository is configured to auto-deploy to GitHub Pages. To manually deploy:

1. **Build and deploy:**
   ```bash
   npm run deploy
   ```

2. **Verify deployment:**
   - Go to your repository Settings → Pages
   - Confirm the source is set to `gh-pages` branch
   - Your game will be live at `https://EduDDJ.github.io/Witch-Nights`

## 📁 Project Structure

- `src/` - React components and game logic
- `src/components/` - Reusable React components
- `public/` - Static assets
- `dist/` - Production build (generated by `npm run build`)

## 🛠 Tech Stack

- **React** 19 - UI framework
- **Vite** 6 - Build tool
- **TypeScript** - Type-safe development
- **Tailwind CSS** 4 - Styling
- **Lucide React** - Icon library
- **Motion** - Animation library
